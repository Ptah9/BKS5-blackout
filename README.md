## идеи:
- графики температура, время, полезные действия, доверие - менбше доверия больше действия для того чтобы тебя слушались
- инвентарь, комбинировать предметы (пример бутылка и телефон фонарик = нормальный свет) => будет добавлять спокойствие толпе (иметь эффект)
- добавить отслеживание своего пульса. Пульс высокий => речь нечеткая
- плашки положение на данный момент
- плашка мыслей с подсказками и инфой
- красный стул в кабине машиниста(если 3+ игрока)
- какойто бабке плохо, с сердцем(ктото из игроков - врач, ему нужно его спасти, мини игра с нажиманием на кнопочки по подсказкам в мыслях)

## Как запустить

```
npm install        # один раз, пока есть интернет
npm run build      # собрать клиент в dist/
npm run cert       # выпустить сертификат для локальной сети
npm start          # https://<ip-машины>:8443
```

Доверие сертификату — один раз на каждой машине (Windows):

```
powershell -ExecutionPolicy Bypass -File tools/trust-cert.ps1
```

Разработка: `npm run dev:server` (http на 8080) и `npm run dev:client`
(Vite на 5173 с прокси на сервер).

Проверка, что всё живо: `node tools/smoke.mjs` — статика, рукопожатие WebSocket, пинг.

Стек: Three.js + TypeScript + Vite на клиенте, Node + `ws` на сервере.
Планы, протокол и обоснования решений — в папке `Flaude` рядом с проектом.
