# Спецификация локаций, левел-дизайна и триггеров окружения

Документ предназначен для AI-агента разработчика (Three.js / Node.js) и содержит техническое описание 3D-сцен, систем освещения, коллизий, интерактивных зон и синхронизируемых состояний.

---

## 1. Топология игрового пространства (Spatial Graph)

Карта состоит из линейной цепочки секций с односторонними и двусторонними переходами:

```
[Тоннель: Зона аварии (Ahead)]
         ▲
         │ (Торцевая дверь кабины)
         ▼
[Кабина машиниста (Cab)]
         ▲
         │ (Служебная дверь с защелкой)
         ▼
[Вагон 1: Головной салон (Main Car)]
         ▲
         │ (Межвагонный переход / закрыт в начале)
         ▼
[Вагон 2: Хвостовой салон (Rear Car)]
         ▲
         │ (Хвостовая аварийная дверь)
         ▼
[Тоннель: Зона эвакуации и ложная сбойка (Behind)]
```

## 2. Детальная спецификация локаций

### Локация 1: Вагон 1 — Головной салон («Котел паники»)

* **Назначение:** Стартовая точка, социальный хаб, зона контроля паники.
* **Габариты Mesh:** $19.2 \times 2.7 \times 2.2$ м (стандарт вагона 81-717).
* **Световые состояния (Lighting States):**
  * `STATE_NORMAL`: 16 потолочных плафонов (теплый белый, `0xfff4e0`, интенсивность 1.0).
  * `STATE_BLACKOUT`: Полная тьма (0.05 сек.), далее переход в `STATE_EMERGENCY`.
  * `STATE_EMERGENCY`: 2 аварийных светодиодных плафона у дверей (тусклый холодный, `0x6688aa`, интенсивность 0.15).
  * `STATE_PHONE_LIGHTS`: Точечные `SpotLight` от экранов и фонариков NPC.
  * `STATE_DIFFUSED_LIGHT`: Активируется крафтом (бутылка + фонарик), мягкий `PointLight` (`0xffeedd`, радиус 6 м, интенсивность 0.8), снимает штраф к видимости.
* **Интерактивные объекты и триггеры:**
  * `obj_window_left_1`, `obj_window_right_2`: Форточки. Требуют удержания `[E]` (2 игрока одновременно в течение 3 сек). Событие: сброс таймера удушья, приток тумана/пара из тоннеля.
  * `obj_driver_call_button`: Переговорное устройство. При клике воспроизводит шум помех, на 3-й клик триггерит реплику паники персонажа.
  * `obj_door_to_cab`: Дверь в кабину. Изначально заперта. Открывается монтировкой / ключом / силой 2 игроков.
* **NPC на старте:** Дед Владимир с велосипедом, Альтушка (ИУ5), Мужик с завода, Учительница математики, Ганвест, Бабка (пациент для мини-игры).

---

### Локация 2: Кабина машиниста («Штаб управления»)

* **Назначение:** Технический узел, радиосвязь, источник критического инвентаря.
* **Габариты Mesh:** $2.2 \times 2.5 \times 2.1$ м. Тесное замкнутое пространство.
* **Визуальные маркеры:**
  * Пульт управления с тумблерами и амперметрами.
  * Микрофон поездной связи (ТГС), раскачивающийся по физике `Verlet` или простой синусоиде на кабеле.
  * Лобовое остекление с видом в абсолютно черный тоннель.
  * Красный стул машиниста (пасхалка/место сидения).
* **Интерактивные объекты:**
  * `obj_announcer_switch`: Тумблер автоинформатора. Клик выключает зацикленную фразу «Оставайтесь в вагонах», снижая прирост паники на $-2$/сек.
  * `obj_mic_intercom`: Микрофон ТГС. Активирует режим вещания на весь состав (используется для диалогов с NPC и кульминации).
  * `obj_cab_door_wedge`: Точка взаимодействия на полу двери. Требует предмет `item_paper_sheet` (конспект/бумажка). Без фиксации дверь захлопывается через 15 секунд.
  * `obj_locker`: Шкафчик за спинкой кресла. Лут:
    * `item_uvn` (Указатель высокого напряжения).
    * `item_medkit` (Жгут, бинт, шина).
    * `item_candy` (Конфеты «Взлетные» — снимают стресс).
    * `item_tubus` (Тубус с начерталкой — триггер мини-игры с карандашом).

---

### Локация 3: Передний тоннель («Зона машиниста»)

* **Назначение:** Хоррор-секция, разведка, спасение машиниста.
* **Габариты Mesh:** Цилиндрический чугунный тюбинг диаметром 5.1 м, протяженность 80 м.
* **Специфика коллизий и навигации (NavMesh):**
  * **Левая сторона (Hazard Zone):** Защитный короб контактного рельса (КР). Коллизия `collider_third_rail`. При входе игрока без флага снятого напряжения — мгновенный урон / Game Over.
  * **Правая сторона (Safe Pathway):** Бетонная банкетка шириной 0.6 м. Только по ней разрешено безопасное перемещение.
* **Динамическое окружение:**
  * Капли конденсата (`ParticleSystem`).
  * Звуки далекого гула и скрежета металла.
  * `obj_blinking_lantern`: Мигающий фонарь на отметке 45 м. Освещает место аварии.
* **Точки интереса (POI):**
  * **Точка 45 м:** Раненый машинист на полу у стены. Рядом брошенная аптечка и разбитый служебный фонарь.
  * **Точка 55 м:** Развилка сбойки. На стене белая меловая стрелка «ВЫХОД» и схематичные рисунки окон (ложный путь).
  * **Точка 60 м:** Телефон тоннельной связи (шкаф СЦБ). Трубка снята, линия мертва.

---

### Локация 4: Задний тоннель и Служебный ходок («Зона эвакуации»)

* **Назначение:** Финальный эвакуационный маршрут, зона перехвата толпы Связиста.
* **Геометрия:**
  * Основной тоннель продолжается назад на 60 м.
  * На отметке -30 м находится поворот под $90^\circ$ — служебный ходок (узкий бетонный коридор $1.8 \times 2.0$ м), ведущий к вентиляционной шахте и платформе.
* **Интерактивные объекты:**
  * `obj_exit_sign`: Стационарный световой указатель «ВЫХОД» над гермодверью в служебный ходок. Изначально обесточен, загорается тускло-зеленым при приближении с фонарем.
  * `obj_rail_check_point`: Точка контакта с рельсом перед сходнями. Требует использования `item_uvn`. Валидирует снятие 825V. Без проверки NPC отказываются спускаться на балластную призму.

## 3. Таблица триггеров и серверных событий сцены

| ID Триггера | Локация | Условие срабатывания | Серверный эмит (WebSocket) | Результат в игровом мире |
| :--- | :--- | :--- | :--- | :--- |
| `trig_blackout` | Вагон 1 | 45 сек. от старта сессии | `SCENE_EVENT: BLACKOUT` | Гаснет свет, спавнятся телефоны, запуск таймера духоты |
| `trig_cab_open` | Кабина | Клик по замку двери кабины | `CABIN_UNLOCKED` | Доступ к пульту и инвентарю кабины |
| `trig_inspector_spawn` | Кабина | Прошло 120 сек. ИЛИ выключен информатор | `NPC_ENTER: INSPECTOR` | Стук в лобовую дверь, вход Обходчика с красным фонарем |
| `trig_crowd_split` | Вагон 2 | Завершение квеста с машинистом в тоннеле | `PANIC_MUTINY: SVYAZIST` | Связист взламывает хвостовую дверь, уводит NPC по стрелке |
| `trig_rail_test` | Тоннель | Использование УВН на рельсе | `THIRD_RAIL_SAFE: TRUE` | Разрешение фазы организованного вывода людей |
| `trig_evacuation_end`| Служебный ходок | 80% живых NPC доведены до гермодвери | `FINALE_TRIGGER` | Запуск финального синематика в зависимости от флагов |

## 4. Архитектура состояний вагона (State Machine)

Для синхронизации Three.js клиента с сервером на Node.js использовать глобальный стейт салона:

```typescript
interface CarWorldState {
  airQuality: number;        // 100 -> 0 (при 0 начинается удушье)
  panicLevel: number;        // 0 -> 100 (при 80+ NPC не слушают команды)
  lightMode: 'normal' | 'blackout' | 'emergency' | 'diffused';
  announcerPlaying: boolean; // Влияет на панику (+2/сек если true)
  doors: {
    cabDoorJammed: boolean;
    rearEmergencyOpen: boolean;
  };
  railVoltageActive: boolean; // true = смерть при наступании
  vladimirTrust: number;     // Связь с AI-агентом Деда
  svyazistConvinced: boolean;// Флаг победы в переговорах
}
```
