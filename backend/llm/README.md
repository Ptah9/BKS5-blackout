# Локальная модель для персонажей

Сервер игры умеет обращаться к локальной модели через Ollama. Модель пишет
реплики от лица NPC: каждому персонажу передаются его `persona` и история
разговора. Настройки персонажей лежат в `content/npcs.json`.

## Запуск на Mac

Установленная модель `qwen3:4b-instruct` подходит для первого теста. Убедитесь,
что Ollama запущена и модель видна:

```bash
ollama list
ollama run qwen3:4b-instruct --think=false
```

Для выхода из интерактивного режима Ollama нажмите `Ctrl+D`. Игровой сервер
самостоятельно передаёт `think: false` для моделей Qwen3 через Ollama API.

В `.env` в корне проекта добавьте или измените настройки:

```dotenv
LOCAL_LLM_URL=http://127.0.0.1:11434
LOCAL_LLM_MODEL=qwen3:4b-instruct
LOCAL_LLM_FORMAT=ollama
```

`127.0.0.1` подходит, когда Ollama и игровой сервер работают на одном Mac.
Переменные `DEEPSEEK_API_KEY` для локального режима не нужны. Не добавляйте
реальные ключи в Git: `.env` уже исключён из истории.

Из корня проекта запустите игру одной командой. Она очистит историю диалогов
NPC перед стартом, затем поднимет сервер и клиент; остальные данные игры
останутся без изменений:

```bash
npm run dev:clean
```

Остановить оба процесса можно сочетанием `Ctrl+C`.

В логе сервера должно появиться сообщение примерно такого вида:

```text
агенты: локальная модель qwen3:4b-instruct (http://127.0.0.1:11434)
```

При обращении к NPC сервер отправляет запрос на
`http://127.0.0.1:11434/api/chat`. Если Ollama или модель недоступны, сервер
переключится на DeepSeek при наличии `DEEPSEEK_API_KEY`, иначе — на встроенные
правила.

## Если игра запускается на другом компьютере

Адрес `127.0.0.1` всегда означает «этот же компьютер». Если игровой сервер
работает не на Mac с Ollama, укажите в `LOCAL_LLM_URL` сетевой адрес Mac,
например `http://192.168.1.25:11434`, и настройте Ollama принимать соединения
из локальной сети. Открывайте доступ только в доверенной сети; не публикуйте
порт Ollama в интернете.

## Другие локальные серверы

Для сервера с OpenAI-совместимым API укажите его базовый URL, имя модели и
`LOCAL_LLM_FORMAT=openai`. Сервер игры использует `/v1/models` для проверки
доступности и `/v1/chat/completions` для диалога.
