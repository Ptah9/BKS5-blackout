## Что уже есть

  Возвращает `{ group, colliders, phones, lamps }`.

- `client/src/render/textures.ts` — общие текстуры (`createTextures()`), не рисуй свои без нужды.

  Дверь в кабину — на `z = −9.55`. Дальше по замыслу идёт кабина, за ней тоннель.

## Что надо сделать

1. **Кабина машиниста** — комната за дверью: пол, стены, потолок, пульт с тангентой,
   кресло машиниста, красный стул (если 3+ игрока — просто второй стул),
   распахнутая дверь наружу, из которой тянет холодом. Размер примерно 2.2 × 2.4 × 2.6 м.
2. **Дверь из кабины в тоннель** — проём в торце кабины, дверь распахнута наружу.
3. **Тоннель** — от кабины вперёд: бетон, кабельные лотки, светофор с трубкой,
   узкая банкетка вдоль стены, дальше замурованный проход с нарисованным мелом «выход».
4. **Платформа** — если останется время: короткий кусок в конце тоннеля.

Каждая локация — отдельный модуль с одинаковым интерфейсом:

```ts
export interface Location {
  group: THREE.Group;
  colliders: Box2[];
  bounds: Bounds;
  lamps: THREE.Object3D[];   // что светится при общем свете
}

export function buildCab(textures: Textures): Location
export function buildTunnel(textures: Textures): Location
```
